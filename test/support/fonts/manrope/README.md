# Références typographiques des tests

Les cinq fichiers Manrope sont les références déjà utilisées par la recette IzyTel. Ils sont conservés dans le dépôt pour que les comparaisons visuelles s’exécutent sans dépendre d’un cache `scratch` ou d’un téléchargement réseau. Les fichiers portant un hash gardent les identifiants utilisés par le descripteur Google Fonts du projet.
