4. NORMALISATION

Avant enregistrement, les tokens reconnus sont convertis en placeholders
canoniques. Dart et SQL appliquent la même règle, avec vecteurs partagés.
Accents, accents décomposés et casse sont tolérés. La ponctuation et les
chiffres des codes ne sont pas réécrits.

  numéro_du_destinataire / numero_du_destinataire / numéro / numero
    -> {{msisdn_local}}
  montant -> {{amount}}
  code_offre / code offre -> {{offer_code}}
  quantité / quantite -> {{quantity}}
  code_secret / code secret -> {{secret_code}}

Les alias sont aussi reconnus à l'intérieur d'accolades doubles complètes.
Les tokens inconnus et accolades incomplètes restent invalides ; aucun texte
arbitraire n'est injecté comme variable. Le stockage garde la forme canonique.

Exemples :
  *412*2*numéro_du_destinataire# -> *412*2*{{msisdn_local}}#
  *133*5*numéro*montant# -> *133*5*{{msisdn_local}}*{{amount}}#
  *410*numéro*montant*code_secret#
    -> *410*{{msisdn_local}}*{{amount}}*{{secret_code}}#

5. PLACEHOLDERS ET SECRET

Disponibles : msisdn_local, amount, offer_code, quantity, secret_code.
Les syntaxes statiques restent valides. Préfixes autorisés : *, ** et # ;
terminaison # ; longueur de code généré maximale 182, template maximal 512.
Les valeurs injectées sont typées/validées et le résultat final est revalidé.
Un paramètre manquant bloque le composeur et laisse le traitement manuel.

Le secret réel est résolu côté serveur depuis private.ussd_secret_configuration,
par réseau et cible ; l'override propre à la cible précède « both ». Sans
override autorisé, le défaut V1 centralisé est 0000. La configuration privée
n'est accessible ni au Manager, ni à l'Agent/Cabiniste, ni via une table client.
Sa gestion demeure réservée à l'administrateur de base ; aucun champ de secret
réel n'est ajouté au Back-office.

Le défaut Dart est centralisé dans UssdEngine.defaultSecretCode et sert aux
aperçus fictifs. Le mobile ne reconstruit pas le code réel : il utilise la
réponse du serveur. Le contexte n'expose qu'une révision UUID opaque ; une
rotation ou suppression/recréation invalide une confirmation antérieure.
Les logs techniques et tables d'audit ne reçoivent pas la valeur du secret
ni le code final. L'affichage final et le composeur contiennent naturellement
le code à exécuter après confirmation de l'utilisateur.

6. BROUILLONS PRÉPARÉS

Le seed crée 12 règles en Brouillon, sans activation :

MOOV
  callBundle : *412*1#
  internetSubscription : *412*2*{{msisdn_local}}#
  famille Folie / callBundle : *412*4*{{msisdn_local}}#
  consultation du solde : *414*{{secret_code}}#
  unitTransfer : *410*{{msisdn_local}}*{{amount}}*{{secret_code}}#

ORANGE
  internetSubscription : #154*1*{{msisdn_local}}#
  callBundle : #154*1*{{msisdn_local}}#
  mixedBundle : #154*1*{{msisdn_local}}#

MTN
  mixedBundle / Pass Appel : *133*6*2*{{msisdn_local}}#
  internetSubscription : *133*6*3*{{msisdn_local}}#
  famille Chic / mixedBundle : *133*6*8*{{msisdn_local}}#
  unitTransfer : *133*5*{{msisdn_local}}*{{amount}}#

Les IDs réseau sont ceux du code : moov, orange, mtn. Orange utilise trois
règles car ses offres Appel emploient deux identifiants métier réellement
présents : callBundle et mixedBundle. unitTransfer existe déjà dans le modèle,
même si aucune offre de ce service n'était présente au contrôle du catalogue.

Moov Folie est une famille contrôlée callBundle, reliée explicitement aux IDs
moov-calls-500, moov-calls-1000, moov-calls-1500, moov-calls-2500, moov-calls-5000.
Les bindings existants sont conservés, sans remplacement d'une décision Admin.

MTN Chic n'a pas de mapping certain : les offres présentes sont Free Plus.
La famille est créée de manière contrôlée, SANS association automatique à ces
offres. Son activation est refusée tant que l'association n'est pas renseignée.
Les libellés ne deviennent pas une clé de sélection des commandes.

La consultation du solde est distinguée par purpose=balance, sans nouveau
service de commande. Elle est consultable/configurable/prévisualisable mais
n'est JAMAIS sélectionnée pour traiter une commande. Aucun nouveau parcours
mobile autonome de consultation du solde n'est ajouté dans cette reprise.
